# max_value

Implemente `max_value(values)` sem usar `max`.

## Arquivo esperado

`max_value.py`

## Comportamento esperado
- Assinatura obrigatória: `max_value(...)`.
- Retorne o valor; o harness do app serializa em JSON.
- Não escreva código de execução no topo do módulo.

## Permitido
- `funções`
- `estruturas nativas`

## Não permitido
- `print dentro da função`
