Assignment name  : max_value
Expected files   : max_value.py
Function         : def max_value(values)
--------------------------------------------------------------------------------

Write a function `max_value` that receives a list of integers and returns the
largest one. If the list is empty, return None.

Do not use the built-in max().

Examples:

max_value([3, 9, 2])    -> 9
max_value([])           -> None   (nothing is shown)
