Assignment name  : add_numbers
Expected files   : add_numbers.py
Function         : def add(a, b)
--------------------------------------------------------------------------------

Write a function `add` that receives two integers and returns their sum.

The function must RETURN the value (do not print it). The trainer calls your
function and shows the returned value as JSON.

Examples:

add(1, 2)    -> 3
add(-5, 5)   -> 0
