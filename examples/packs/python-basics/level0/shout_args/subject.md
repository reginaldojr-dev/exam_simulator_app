Assignment name  : shout_args
Expected files   : shout_args.py
Allowed functions: print, sys.argv, str.upper
--------------------------------------------------------------------------------

Write a program that prints all command-line arguments in UPPERCASE on a
single line, separated by exactly one space, followed by a newline.

If no argument is given, print only a newline.

Examples:

$> python shout_args.py hello World | cat -e
HELLO WORLD$
$> python shout_args.py | cat -e
$
