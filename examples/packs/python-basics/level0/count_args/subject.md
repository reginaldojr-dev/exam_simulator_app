Assignment name  : count_args
Expected files   : count_args.py
Allowed functions: print, len, sys.argv
--------------------------------------------------------------------------------

Write a program that prints how many command-line arguments it received
(not counting the program name), followed by a newline.

Examples:

$> python count_args.py a b c | cat -e
3$
$> python count_args.py | cat -e
0$
