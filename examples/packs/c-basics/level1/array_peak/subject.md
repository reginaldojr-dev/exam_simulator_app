# array_peak

Receba inteiros pelos argumentos e imprima o maior valor encontrado.

## Arquivo esperado

`array_peak.c`

## Comportamento esperado
- Se não houver números, imprima `0`.
- Os argumentos podem ser negativos.
- Assuma entradas numéricas válidas.

## Permitido
- `write`

## Não permitido
- `printf`
- `qsort`

## Exemplos

Entrada/args: `./array_peak -8 -2 -9`

Saída:

```text
-2
```
