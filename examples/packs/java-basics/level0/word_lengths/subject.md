# word_lengths

Imprima cada argumento seguido do seu tamanho.

## Arquivo esperado

`WordLengths.java`

## Comportamento esperado
- Classe pública obrigatória: `WordLengths`.
- Formato de cada linha: `palavra:tamanho`.
- Sem argumentos, não imprima nada.

## Permitido
- `String.length`

## Não permitido
- `Scanner`

## Exemplos

Entrada/args: `java WordLengths java oop`

Saída:

```text
java:4\noop:3
```
