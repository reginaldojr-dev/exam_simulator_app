# sum_args

Some os argumentos inteiros recebidos em `main`.

## Arquivo esperado

`SumArgs.java`

## Comportamento esperado
- Classe pública obrigatória: `SumArgs`.
- Imprima somente a soma seguida de newline.
- Sem argumentos, imprima `0`.

## Permitido
- `Integer.parseInt`

## Não permitido
- `Scanner`

## Exemplos

Entrada/args: `java SumArgs 1 2`

Saída:

```text
3
```
