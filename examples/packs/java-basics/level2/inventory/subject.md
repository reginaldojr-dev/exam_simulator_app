# inventory

Crie uma pequena classe de domínio para acumular quantidades.

## Arquivo esperado

`InventoryApp.java + Inventory.java`

## Comportamento esperado
- `InventoryApp` deve conter o `main`.
- `Inventory` deve expor `add(int)` e `total()`.
- Compile e rode com os dois arquivos.

## Permitido
- `classes`
- `campos privados`

## Não permitido
- `estado global`

## Exemplos

Entrada/args: `java InventoryApp 2 5`

Saída:

```text
7
```
