# word_score

Calcule a soma dos códigos ASCII dos caracteres de uma string.

## Arquivo esperado

`word_score.cpp`

## Comportamento esperado
- Assinatura: `int word_score(const std::string& text);`
- Não escreva `main`.
- A função deve funcionar para string vazia.

## Permitido
- `string`

## Não permitido
- `numeric`

## Exemplos

Entrada/args: `word_score("abc")`

Saída:

```text
294
```
